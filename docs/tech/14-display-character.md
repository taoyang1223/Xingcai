# 14 · 客户展示角色（2026-09-25）

客户在屏幕上看到的人，不再用程序化无头人台，也不再用方块粗模。完成度对标 Blender Studio 的角色 Snow：风格化、部件分开、材质能分出皮肤和衣服，站着就能认出是一个人。

围度、选码仍走自有参数 \(\beta\)。展示角色只负责让客户相信「这是我的体型」，不负责从顶点上量胸围、腰围、臀围。

## 1. 两套东西分开

| | 量体 | 展示 |
| --- | --- | --- |
| 是什么 | \(M(\beta)\)：身高、胖瘦、肚子、肩宽，以及由此算出的围度 | 一具风格化角色 |
| 客户是否直接看见 | 看见滑杆和围度数字 | 看见这个人 |
| 头 | 不从照片重建五官 | 人人相同的通用头 |
| 精度标准 | 软尺误差、字段字典 | 对标 Snow 的完成度 |

禁止再把「截面样条挤出来的光滑胶囊」或「默认立方体挤出的方块人」当成交付物。仓库里的 `body.ts` 和 `mannequin_headless_v1.glb` 只留作旧管子，不再加功能。

## 2. 对标 Snow 的完成度

Snow（`snow_v4.2`，CC BY）是参照，不是要整具放进产品。参照的是这些看得见的事实：

- 身体大约 5800 个顶点就够。好看来自分开的部件和贴图，不靠把皮肤堆到几十万面。
- 头、头发、眼睛、眉毛、牙齿分开。衣服至少分 T 恤、裤子、鞋。
- 皮肤和布料材质不同。金属度低，衣服不要反光成塑料。
- 肩、腰、臀的轮廓站着就能读出来。
- 姿态是清楚的站姿。滑杆改变的是体型，不是换成另一套衣服。

不做的部分：Snow 那套约 1500 根控制器骨骼、面部表情形态键。那些是动画练习用的。FitMe 的展示只用三个形态键改体型。

| 滑杆 | 形态键 | 拉到 1 时 |
| --- | --- | --- |
| 整体胖瘦 | `BS_Fat` | 躯干为主，四肢稍弱。头不要胀成球 |
| 肚子 | `BS_Belly` | 腰腹往前鼓，侧面能看出厚度 |
| 肩宽 | `BS_Shoulder` | 肩带变宽，上臂根跟着外移 |

名字区分大小写。身高仍是整体缩放，基准 170 cm。

## 3. 通用头

头是产品自带的样式，所有用户看同一张，不随照片变化，不做人脸识别。

第一种样式是 Snow 的头：

- 文件：`apps/fitme/public/mannequin/heads/snow_head_v1.glb`（约 2.6 MB，12 块网格）
- 许可与署名：`docs/licenses/snow-head.txt`
- 署名原文：`Snow Rig (CC) Blender Foundation | studio.blender.org`

拍照时照片里的脸仍在手机端糊掉，不入库。话术写「我们不使用你的脸」，因为通用头不是用户本人。

## 4. 交付限额

| 项 | 要求 |
| --- | --- |
| 格式 | glTF Binary，Y-up，单位米 |
| 三角面 | ≤ 25000 |
| 文件 | ≤ 8 MB。Draco 可选 |
| 材质 | 皮肤与衣服分开。皮肤金属度 ≤ 0.05，粗糙度 ≥ 0.8 |
| 授权 | 自建，或带署名的 CC BY 部件。禁止未授权的 SMPL |

低端机帧率不够时退回静态图，不许白屏。

批量怎么从一具角色产出全部体型，公式见 [《15》](./15-batch-production.md)。
