# Blender 5.2 官网建模流程

依据 Blender 5.2 英文手册整理，手册在 `docs/blender-5.2-manual/`。线上原文：<https://docs.blender.org/manual/en/5.2/modeling/introduction.html>。

手册版权归 Blender Documentation Team，页面许可为 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。下文是章节顺序的转述，不是原文照抄。

手册没有单独的「人物设计作业」。它把设计一个模型写成下面这条任务顺序。一个场景至少要有三样东西：模型、材质、灯光。建模只负责第一样：做出一块表面。

## 1. 先定表面类型

编辑模式能改的对象有网格、曲线、曲面、融球、文字、晶格。场景里最常用的是网格。

同一章后面还有新曲线、点云、体积、空物体。空物体没有表面，用来做参照。

## 2. 三种模式分工

| 模式 | 手册里的用途 |
| --- | --- |
| 物体模式 | 新建物体、合并物体，管理形态键和 UV / 颜色层 |
| 编辑模式 | 改多边形，网格建模的主要地方 |
| 雕刻模式 | 用笔刷把网格当成泥来推 |

做模型时会在这几种模式之间来回切。有的工具只在一种模式里出现。

## 3. 网格由什么构成

网格只有三种基本元件：

- **顶点**：三维空间里的一个点。一个物体的顶点存在一份坐标数组里。物体原点不是顶点。
- **边**：连接两个顶点的直线。线框里能看见，渲染图里通常看不见。边用来围出面。
- **面**：真正的表面，也是渲染时看见的部分。一块区域如果没有面，就是空的。

## 4. 从基本体摆出大形

网格建模的典型起手是：用基本体把大形摆出来，再用工具加细节。

加入方式：物体模式或编辑模式，菜单 `Add → Mesh`，快捷键 `Shift-A`。基本体出现在三维游标的位置。

手册列出的标准网格基本体包括立方体、UV 球体、圆柱等。

## 5. 在编辑模式里加细节

编辑模式是改点、边、面的地方。手册把这一段拆成：

1. **选择**：点、边、面，以及环、相连部分、相似元素。
2. **变换**：移动、旋转、缩放，以及推向球形、切变、弯曲。
3. **结构工具**：挤出（Extrude）、环切（Loop Cut）、多边形搭建（Poly Build）、旋转复制（Spin）。
4. **网格属性**：法线、光滑着色等，决定表面怎么受光。

人物这类形体，手册的路径就是：基本体 → 挤出和环切拉出头、四肢 → 再调顶点。

## 6. 需要自由形状时进入雕刻

雕刻与绘制是另一套编辑方式，靠笔刷，不靠逐个顶点。

- **雕刻**：改变网格的形状和拓扑。
- **顶点色**：改顶点颜色属性。
- **权重绘制**：改顶点组权重。
- **纹理绘制**：改贴图上的像素。

雕刻适合肌肉、脸这类用挤出不好控的表面。

## 7. 用修饰器做非破坏性加工

修饰器是自动作用在物体几何上的操作，不改你正在编辑的那份基础网格。它改变的是显示和渲染的结果。可以叠成一个栈，后加的在栈底、最后生效。确认之后可以 Apply，把结果写进网格。

四类内置修饰器：

- **编辑**：多半改顶点组这类数据，不直接改几何。
- **生成**：会改变拓扑，例如细分曲面，用来把方块表面变圆。
- **形变**：只改形状，不改拓扑。
- **模拟**：物理和粒子，多数在打开模拟时自动加进栈。

用户也可以用几何节点做自己的修饰器。

## 8. 拓扑乱了就重铺

雕刻或反复挤出之后，布线会乱。手册提供两种处理：

- **自动重铺（Remesh）**：按体素或四边流重建出比较均匀的网格。体素重铺适合清理雕刻结果和打印。手册写明，它不适合作为会变形的角色的最终布线。
- **手动重拓扑**：新建一层贴在旧表面上的网格，用重拓扑叠加显示、Poly Build 和吸附，把边重新铺到该变形的位置。

## 9. 展开 UV

网格要贴图时，先做 UV。手册把这一段放在网格章末尾：UV 与纹理空间、缝合边（Seams）、展开（Unwrap）。展开之后，纹理绘制和材质节点才能把图片对到表面上。

## 10. 材质和灯光

材质决定物体看起来像什么材料：颜色、纹理，以及光怎么和它作用。常用 Principled BSDF，可以做出塑料、玻璃、金属、布料、皮肤等。在材质属性或着色器编辑器里搭节点。着色工作区可以用材质预览或渲染视图看结果。

灯光不属于建模章，但手册在建模开头写明：场景要能被看见，还得有灯光。

## 11. 用节点按参数生成几何

几何节点是另一条建模路：给物体加 Geometry Nodes 修饰器，在几何节点编辑器里用节点改几何。节点树吃的是修饰器之前的几何（原始网格，或上一个修饰器的结果）。基本体、挤出、变形都可以做成节点，而不是只在视图里拖顶点。

## 手册里的章节顺序

建模章的目录顺序就是上面的任务顺序：

1. 介绍与模式
2. 网格：结构、基本体、工具、选择、编辑、属性、UV、重铺
3. 曲线、曲面、融球、文字、点云、体积、空物体
4. 修饰器
5. 几何节点
6. 变换

雕刻与绘制、材质、灯光在建模章之外，接在表面完成之后。
