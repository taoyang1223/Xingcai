FITME · 图纸 12 · 手绘工作流

精致人台怎么来：工厂做一次，App 用一万次

Maya / AI 只在离线工厂里干活。用户手机从不调用建模软件，也不把原图喂给大模型雕一具新模。 客户看见的是货架上的人台，看不见车间。

A离线工厂 · 做一具好看的无头人台，全用户共用

精致感来自资产与光照，不是来自引擎。一次，不是每人一次。

1 美术 / AI

Maya 或 Blender 雕模。AI 可辅助出草稿。磨砂无头，不做脸。

一次，不是每人一次
2 三个形态

BS_Fat 整体胖瘦 · BS_Belly 肚子（侧面关键）· BS_Shoulder 肩宽。

名字写进合同，不许乱改
3 导出 GLB

glTF 二进制，面数 ≤5k，Draco 压缩目标 ≤2MB，附 manifest.json。

App 只认这个文件
4 挂上 CDN

进捏人页才下载。Web 与以后 Flutter 共用同一资产。

禁止两端各做一套网格
交付物

mannequin_headless_v1.glb + 三 morph + 授权留档 docs/licenses/。

精致感来自这里

B在线 · 每个用户只写一组参数 β

拖一下立刻变。秒级，不是等工厂工单。

1 手机建档

阶段 1 拖三根杆。阶段 2 正侧两张 + 身高。贴身、靠墙、倒计时。

不填 22 个厘米
2 端侧先拦

废片 / 裸露 / 卫衣拦截。糊脸后才考虑上传。须有 consent_id。

原图不进业务库
3 反解 β

height / fat / belly / shoulder。围度从同一具 M(β) 上量出。

SDK 不当档案真相
4 驱动 GLB

β → morph 权重，身高走缩放。three.js 可转侧面看肚子。

拖一下立刻变
5 看码

手填尺码表。主码 + 部位诊断 + 置信度。该拦就拦。

选码才是产品
用户看见

「这是我的体型」「这件穿 M」。看不见 Maya，看不见 GPT。

秒级

×不要做成主路径　　…以后可选

每人拍照 → GPT 调 Maya → 雕新模 → 导回 App

  • Maya 不是 Web API：要许可、无头机、分钟级、很难扩
  • 大模型雕不出可复现的围度，档案对不齐、选码会漂
  • 原图进公有模型 = 隐私红线（糊脸、短存、不训练）
  • 用户要「拖一下立刻变」，不是等工厂工单

异步精渲染海报（阶段 4）

  • 同一组 β 丢给服务端（Maya / UE 离线渲）
  • 回传图或短视频，不是每人一具不可比网格
  • 排队、分钟级可以；绝不挡选码主路径
  • 精致加在同一套数据上，不必换故事
一句话：Maya 是工厂，β 是档案，GLB 是货架。客户看见货架上的人，看不见车间。
